## Summary
Haiku's classic interface colours for KDE applications.

## Description
Light grey panels (216), white views, purple-blue selection, pale yellow tooltips, blue keyboard focus and the yellow window title colour of Haiku R1.

Note: KWin ignores the `[WM]` title bar colours of colour schemes that define a header colour set (like this one). The yellow tab therefore comes from the Haiku window decoration itself, not from this scheme.
