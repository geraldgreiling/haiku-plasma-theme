## Summary
Haiku / BeOS look for Plasma 6: yellow window tabs, grey bevelled widgets, blue desktop.

## Description
A global theme inspired by the Haiku R1 desktop (and its ancestor BeOS).

**This global theme ties the following parts together – please install them as well:**
- Plasma Style "Haiku" – STORE_LINK_PLASMA_STYLE
- Colour scheme "Haiku R1" – STORE_LINK_COLORS
- Icons "Haiku" – STORE_LINK_ICONS
- Cursors "Haiku Cursors" – STORE_LINK_CURSORS
- Window decoration + application style (compiled C++ plugins):
  Arch / CachyOS / Manjaro: AUR package `haiku-plasma-theme-plugins`
  Other distributions: build from source – https://github.com/geraldgreiling/haiku-plasma-theme
- No AUR? Use the Aurorae decoration "Haiku (Aurorae)" instead – STORE_LINK_AURORAE

What the global theme sets: colour scheme, Plasma style, icons, cursors, window decoration "Haiku" (C++), application style "Haiku", Haiku-like splash screen. With "Use desktop layout from theme" you also get a Deskbar-style panel at the top and the blue Haiku desktop; close button left, zoom right, double-click on the tab minimises.
If the compiled plugins are not installed, Plasma falls back to Breeze for the window decoration and application style.

Requires Plasma 6.3 or newer.
