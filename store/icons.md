## Summary
Colourful Haiku-style icons – folders, places, devices, file types, all KDE Gear applications and many popular apps.

## Description
272 original icons drawn in the visual language of Haiku: slight 3/4 perspective, saturated gradients and dark outlines. Includes the standard folders (home, desktop, documents, downloads, music, pictures, videos, …), trash, drives, common file types, core applications an icon for every application of KDE Gear 26.08 (Okular, Ark, Kdenlive, KMail, Konversation, the KDE games and education apps, …) and function icons for about 60 popular third-party applications (web browsers, office suites, image editors, media players, messengers, IDEs, game launchers, system tools), plus about 470 alias names.

The third-party icons deliberately do not imitate the applications' logos – they show what the program does (browser window, paint brush, film screen, …) and replace the logo in menus and task bars. Browsers are told apart by colour and initial.

Everything else is inherited from Breeze, so make sure Breeze icons are installed. All icons are scalable SVGs.

Part of the Haiku global theme: STORE_LINK_GLOBAL_THEME

Not an official Haiku project; no Haiku or BeOS artwork was copied.
