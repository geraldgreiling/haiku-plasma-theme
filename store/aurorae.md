## Summary
Yellow Haiku-style title bar – no compiling needed.

## Description
SVG (Aurorae) version of the Haiku window decoration for every distribution: yellow title bar for the active window, grey for inactive windows, Haiku-style close and zoom buttons.

Unlike the real Haiku look, the title bar spans the full window width (Aurorae cannot draw a tab that is only as wide as the title). For the authentic narrow yellow tab use the compiled decoration: AUR package `haiku-plasma-theme-plugins`, or build it from source (https://github.com/geraldgreiling/haiku-plasma-theme).

Part of the Haiku global theme: STORE_LINK_GLOBAL_THEME
