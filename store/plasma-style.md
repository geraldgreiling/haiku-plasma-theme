## Summary
Grey bevelled Plasma style inspired by Haiku's Deskbar.

## Description
Plasma style for Plasma 6 with Haiku-like panels, popups, tooltips (pale yellow), task manager buttons, buttons and text fields. Fully opaque, no blur, pixel-sharp bevels. Elements that are not part of this style fall back to Breeze.

Best combined with the colour scheme "Haiku R1" (STORE_LINK_COLORS) – text colours come from the active colour scheme.
Part of the Haiku global theme: STORE_LINK_GLOBAL_THEME

Not an official Haiku project; all artwork is original.
